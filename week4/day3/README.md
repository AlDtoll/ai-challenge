# День 18 — Планировщик и фоновые задачи (week4/day3)

MCP-сервер с инструментами расписания + агент 24/7, который периодически выдаёт сводку.

## Что демонстрирует задание
- **Сохранение данных** — JSONL-журнал `~/.ai-challenge/day18_weather.jsonl` (append-only, переживает перезапуск).
- **Выполнение по расписанию** — фоновый планировщик (корутина) каждые N секунд собирает погоду.
- **Агрегированный результат** — инструмент `get_summary` (кол-во замеров, мин/средняя/макс температура, период).
- **Агент 24/7** — запускает наблюдение через MCP и в бесконечном цикле печатает сводку.

## Инструменты MCP
- `start_watch(city, interval_sec)` — запустить фоновый сбор погоды.
- `get_summary()` — агрегат по журналу.
- `stop_watch()` — остановить сбор.

## Архитектура (один процесс)
1. Поднимается MCP-сервер (Streamable HTTP, localhost:3002) с тремя инструментами.
2. Агент подключается, через `start_watch` запускает фоновый сбор (wttr.in, каждые 8с → JSONL).
3. Агент в цикле каждые 16с зовёт `get_summary` и печатает сводку. Работает 24/7 (Ctrl+C — выход).

## Запуск
Windows (PowerShell):
```
chcp 65001
.\gradlew.bat :week4:day3:run --console=plain -q
```
Linux/Mac:
```
./gradlew :week4:day3:run --console=plain -q
```
