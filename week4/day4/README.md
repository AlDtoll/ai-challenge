# День 19 — Композиция MCP-инструментов / пайплайн (week4/day4)

MCP-сервер с тремя инструментами + агент, который выполняет их цепочкой, передавая
результат одного на вход следующего.

## Инструменты MCP
- `search(query)` — получить данные: вводный текст статьи Wikipedia (ru).
- `summarize(text)` — обработать: краткая выжимка через DeepSeek (LLM).
- `save_to_file(content, filename)` — сохранить результат в `~/.ai-challenge/`.

## Пайплайн (в агенте)
```
search("Кофе") → текст
   → summarize(текст) → выжимка
       → save_to_file(выжимка) → путь к файлу
```
Агент печатает выход каждого шага → видно автоматическое выполнение цепочки и корректную
передачу данных между инструментами.

## Что закрывает задание
- ✅ несколько MCP-инструментов (search/summarize/save)
- ✅ пайплайн: 1-й получает, 2-й обрабатывает, 3-й сохраняет
- ✅ автоматическое выполнение цепочки
- ✅ корректная передача данных между инструментами

## Запуск
Тема задаётся через --args (по умолчанию «Кофе»):

Windows (PowerShell):
```
chcp 65001
.\gradlew.bat :week4:day4:run --args="Кофе" --console=plain -q
```
Linux/Mac:
```
./gradlew :week4:day4:run --args="Кофе" --console=plain -q
```

> Нужен DEEPSEEK_API_KEY в корневом `.env` (он там уже есть). Run-task сам его подхватывает.
