# Day 26 — сценарий видео (немой скринкаст)

Формат как всегда: **что печатаю → что получаю → следующий шаг**. Звука нет. Целевая длина 2–3 мин. Кадр не переключается.

## Подготовка перед записью (не в видео)

1. Прогреть модель (иначе `load_duration` в первом промпте будет 3-5 сек = скучный кадр):
   ```powershell
   ollama run qwen2.5:7b "здорово"
   ```
   Модель загрузится в VRAM. Второй запуск быстрее — 200-400 мс load вместо 3-5 сек.
2. Открыть 3 окна PowerShell в одном профиле терминала (Windows Terminal), расставить:
   - **Окно A** (слева, широкое) — Kotlin-запуск.
   - **Окно B** (справа сверху) — `nvidia-smi`.
   - **Окно C** (справа снизу) — `ollama` CLI.
3. Настроить консоль (один раз, до записи):
   ```powershell
   chcp 65001
   [Console]::OutputEncoding = [System.Text.Encoding]::UTF8
   $env:JAVA_HOME = "C:\Program Files\Android\Android Studio2\jbr"
   $env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
   ```
4. `cd C:\D\Develop\ai-challenge` в окне A.
5. `git checkout week6/day1` + `git pull` (или `git fetch + git checkout week6/day1`).
6. Удалить старый `day26_report.md` если остался (`del week6\day1\day26_report.md`) — чтобы в конце было видно как файл создаётся.
7. Пустой чёрный фон вокруг окон, ничего лишнего на рабочем столе.

## Сценарий

### Кадр 1. Что стоит и что видит железо (10 сек)

**Окно C:**
```powershell
ollama list
```

Ожидаемый вывод (пример):
```
NAME                          ID              SIZE      MODIFIED
qwen2.5:7b                    845dbda0ea48    4.7 GB    2 hours ago
nomic-embed-text:latest       0a109f422b47    274 MB    5 days ago
```

Пауза 1 сек — читаешь `qwen2.5:7b`.

**Окно B:**
```powershell
nvidia-smi
```

Ожидаемый вывод: карта RTX 3060 Laptop, 76 MiB / 6144 MiB, GPU-Util 0%. Пауза 1 сек.

### Кадр 2. Быстрая проверка в CLI (15 сек)

**Окно C:**
```powershell
ollama run qwen2.5:7b
```

Дождаться `>>> Send a message`. Ввести:
```
Столица Австралии одним словом
```

Enter. Модель отвечает `Канберра.` (за 0.5-1 сек, если прогрета).

```
>>> /bye
```

Выйти.

### Кадр 3. Показать код в IDE (20 сек)

Открыть IDE (Android Studio2). Раскрыть проект `ai-challenge` → `week6/day1/src/main/kotlin/Main.kt`.

Показать 4 куска, скроллом:
- **`OllamaClient` класс** — `chat()` с endpoint `/api/chat`.
- **`healthCheck()`** — `GET /api/version` + `/api/tags`.
- **`buildPrompts()`** — 3 промпта с `checker: (String) -> Boolean`.
- **`writeReport()`** — генерация markdown.

Не задерживаться, ~5 сек на каждый.

### Кадр 4. Запуск (60 сек — это основа видео)


## Если что-то пойдёт не так

- Первый ответ **очень** долгий (`load_duration` >5 сек) — забыл прогреть модель. Прервать, `ollama run qwen2.5:7b "hi"`, повторить.
- `[✗]` где-то в промпте — модель ответила не так как ожидали. Пересмотреть промпт в `buildPrompts()` (маловероятно на qwen2.5:7b, все три оттестированы).
- `nvidia-smi` показывает 0% GPU-Util во время генерации — модель на CPU. Проверить что `ollama serve` работает и не блокируется брандмауэром. См. также `~/.ollama/logs/server.log`.
