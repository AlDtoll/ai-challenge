# Сценарий видео — День 17: Первый инструмент MCP (week4/day2)

Немой скринкаст консоли. Без озвучки. Формат: что печатаю → что получаю.
Программа неинтерактивная: один запуск поднимает свой MCP-сервер, агент вызывает инструмент и печатает результат.

---

## ШАГ 1 — запуск

Печатаю (Windows PowerShell; chcp 65001 — чтобы русские буквы не были кракозябрами):
```
chcp 65001
.\gradlew.bat :week4:day2:run --console=plain -q
```
(на Linux/Mac: `./gradlew :week4:day2:run --console=plain -q`)

Получаю:
```
MCP-сервер поднят: http://localhost:3001/mcp
Агент подключился к серверу
Инструменты сервера: get_forecast
Вызываю get_forecast(latitude=55.03, longitude=82.92)
Результат инструмента: температура 12.3°C, ветер 8.5 км/ч
Ответ агента: сейчас в Новосибирске — температура 12.3°C, ветер 8.5 км/ч
```

(Видно весь путь: свой сервер поднялся → агент подключился → нашёл инструмент get_forecast → вызвал его с координатами → получил и использовал результат. Числа — реальная погода.)

---

**Заметки для съёмки:**
- Прогнать один раз заранее, чтобы зависимости скачались и в кадре не было лога загрузки.
- `--console=plain -q` убирает прогресс-бар Gradle, остаётся чистый вывод программы.
- Если хочется показать и КОД — открой Main.kt: addTool (регистрация инструмента) и callTool (вызов из агента).
