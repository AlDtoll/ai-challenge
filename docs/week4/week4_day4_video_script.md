# Сценарий видео — День 19: Композиция MCP-инструментов / пайплайн (week4/day4)

Немой скринкаст консоли. Без озвучки. Формат: что печатаю → что получаю.
Программа неинтерактивная: один запуск прогоняет цепочку search → summarize → save_to_file.

---

## ШАГ 1 — запуск

Печатаю (Windows PowerShell; chcp 65001 — чтобы кириллица читалась):
```
chcp 65001
.\gradlew.bat :week4:day4:run --args="Кофе" --console=plain -q
```
(на Linux/Mac: `./gradlew :week4:day4:run --args="Кофе" --console=plain -q`)

Получаю:
```
MCP-сервер поднят: http://localhost:3003/mcp
Агент подключился. Инструменты: search, summarize, save_to_file

=== ПАЙПЛАЙН для запроса: «Кофе» ===

[1/3 search] получено 250 символов:
    Ко́фе — напиток из жареных и перемолотых зёрен кофейного дерева…

[2/3 summarize] выжимка:
    Кофе — бодрящий напиток из жареных зёрен кофейного дерева, содержащий кофеин.

[3/3 save_to_file] Сохранено: ...\.ai-challenge\day19_кофе.txt (78 байт)

=== Пайплайн завершён ===
```

Видно весь смысл: 1-й инструмент достал данные → его выход ушёл во 2-й (выжимка через DeepSeek) → выход 2-го ушёл в 3-й (сохранение в файл). Цепочка автоматическая, данные корректно передаются между инструментами.

## ШАГ 2 (опционально) — показать сохранённый файл
```
type %USERPROFILE%\.ai-challenge\day19_кофе.txt   (Windows)
cat ~/.ai-challenge/day19_кофе.txt                 (Linux/Mac)
```
→ в файле лежит выжимка — финальный результат пайплайна.

## ШАГ 3 (опционально) — другая тема
```
.\gradlew.bat :week4:day4:run --args="Кошка" --console=plain -q
```
→ та же цепочка отработает для другого запроса.
