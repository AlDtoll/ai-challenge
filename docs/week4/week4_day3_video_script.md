# Сценарий видео — День 18: Планировщик и фоновые задачи (week4/day3)

Немой скринкаст консоли. Без озвучки. Формат: что печатаю → что получаю.
Программа работает 24/7 — записываешь ~1 минуту, видно несколько сборов и пару сводок.

---

## ШАГ 1 — запуск

Печатаю (Windows PowerShell; chcp 65001 — чтобы русские буквы были читаемы):
```
chcp 65001
.\gradlew.bat :week4:day3:run --console=plain -q
```
(на Linux/Mac: `./gradlew :week4:day3:run --console=plain -q`)

Получаю (программа крутится; ниже фрагмент за ~40 секунд):
```
MCP-сервер поднят: http://localhost:3002/mcp
Журнал данных: C:\Users\...\.ai-challenge\day18_weather.jsonl
Агент подключился. Инструменты: start_watch, get_summary, stop_watch
start_watch -> Наблюдение запущено: Novosibirsk, каждые 8с
Агент работает 24/7. Сводку печатаю каждые 16с. (Ctrl+C — выход)
  [сбор] 2026-06-28 05:20:10  Novosibirsk: 19.0°C, Clear
  [сбор] 2026-06-28 05:20:18  Novosibirsk: 19.0°C, Clear
[СВОДКА] Сводка по «Novosibirsk»: замеров 2; темп. мин 19.0 / средняя 19.0 / макс 19.0; период ...
  [сбор] 2026-06-28 05:20:26  Novosibirsk: 19.0°C, Clear
  [сбор] 2026-06-28 05:20:34  Novosibirsk: 19.0°C, Clear
[СВОДКА] Сводка по «Novosibirsk»: замеров 4; ...
```

Видно весь смысл задания: фоновый планировщик собирает погоду по расписанию ([сбор] каждые 8с), пишет в JSON-журнал, а агент 24/7 периодически зовёт MCP-инструмент get_summary и печатает агрегированную сводку ([СВОДКА] каждые 16с).

## ШАГ 2 (опционально) — показать персистентность
Останови (Ctrl+C) и запусти снова — счётчик «замеров N» в сводке продолжится с прежнего числа (данные сохранены в журнале, не обнулились).

---

**Заметки для съёмки:**
- Прогони один раз заранее, чтобы зависимости скачались и в кадре не было лога загрузки.
- Достаточно ~40–60 секунд записи: видно 2–3 сводки и рост счётчика замеров.
- Ctrl+C завершает (агент «работает 24/7», останавливаешь вручную).
