# Harness Kit — набор техник для улучшения LLM-агентов

Практическая выжимка из [AI Challenge](../INDEX.md): каждый файл — одна техника с готовым кодом на Kotlin и инструкцией «как встроить в свой агент».

**Для кого:** для другого агента (Claude Code / Cursor / Continue / кастомный) который хочет улучшить свой execution loop, контекст-менеджмент, RAG, безопасность или инструментальные вызовы.

**Как использовать:**

1. Посмотри [INDEX.md](INDEX.md) — категоризированное оглавление по темам
2. Открой нужный файл, прочитай «What it improves» и «When to use»
3. Скопируй Kotlin-пример, адаптируй под свой стек (Python / TypeScript / Go — паттерн переносим)
4. Проверь по «Metrics» что реально помогло

**Отличие от [INDEX.md челленджа](../INDEX.md):** тот — фактологический справочник «что было сделано в каждом дне». Этот — actionable-рецепты «что взять и куда встроить». Один и тот же исходный код через другую линзу.

**Статус:** PILOT (2 файла из 30+ планируемых). Формат в стадии согласования с автором.
