# Немой скринкаст — День 31

Формат такой же, как в неделях 4–6: без голоса, только консоль.

## Сцены

1. **Заставка (2 сек)** — «День 31 — Ассистент разработчика».
2. **PowerShell**: перейти в корень репо, `chcp 65001`, показать `git branch --show-current` → `week7/day1`.
3. `.\gradlew.bat :week7:day1:run` — показать:
   - `Ingest: нашёл N md-файлов`
   - `Индекс построен: K чанков`
   - `MCP git-сервер поднят на localhost:3001`
   - `MCP tools доступны: get_current_branch, git_status, git_log`
4. **Вопрос 1**: `/help что содержит проект week4?` → ответ по RAG, источники `[S1] docs/...`.
5. **Вопрос 2**: `/help на какой я ветке?` → отвечает `week7/day1`, дёрнув MCP `get_current_branch`.
6. **Вопрос 3** (изменяем файл в другом окне, потом возвращаемся): `/help какие сейчас изменения в репо?` → ответ через `git_status`, показывает свежий diff.
7. **Вопрос 4**: `/help последние коммиты недели 6?` → ответ через `git_log`.
8. `/quit`.
9. **Конец (2 сек)** — «Готово».

## Что подсвечиваем в описании

- REPL + MCP + RAG в одном процессе.
- MCP — свой, не готовый npm-плагин.
- LLM — DeepSeek (не локальный, показывает что стек модульный).
