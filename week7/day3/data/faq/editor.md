# FAQ — Редактор

## Настройки темпа рендера

Настройка темпа находится в `Editor → Toolbar → Advanced settings → Rendering pace`. По умолчанию скрыта — включается флагом `beta.editor_advanced` в `Settings → Feature flags`.

## Экспорт проекта

Форматы: JSON, YAML, Kotlin DSL. Кнопка «Export» в правом верхнем углу редактора. При экспорте применяются только сохранённые изменения (Ctrl+S).

## Горячие клавиши

- `Ctrl+K` — палитра команд.
- `Ctrl+Shift+F` — поиск по всему проекту.
- `Ctrl+P` — быстрое открытие файла.
- `F2` — переименовать символ.
