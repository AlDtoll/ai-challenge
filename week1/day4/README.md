# Day 4 — Temperature

Same prompt, three temperatures: 0.0 / 0.7 / 1.2

| Temperature | Best for |
|-------------|----------|
| 0.0 | Facts, code, deterministic answers |
| 0.7 | Balanced — accuracy + variety (default) |
| 1.2 | Creativity, brainstorming, unusual ideas |

## Setup

Create `.env` in the project root (`ai-challenge/.env`):
```
DEEPSEEK_API_KEY=sk-...
```

## Run

Open `ai-challenge/` in Android Studio, select `:week1:day4` in Run Configurations and click Run.

Or via terminal:
```bash
./gradlew :week1:day4:run
```
