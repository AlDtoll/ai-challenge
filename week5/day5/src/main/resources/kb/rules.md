# Правила нашего AI-челленджа

## Ветки и main

В этом челлендже мы придерживаемся строгого правила: **в main НИЧЕГО не мёржим**. Каждый день лежит в отдельной ветке `week{N}/day{N}` и в отдельной папке `week{N}/day{N}/`. Дни между собой тоже не сливаются. `main` пустая и используется только как база для новых веток.

Причина: репозиторий публичный, участники сравнивают решения; смешивание дней в main портит историю и запутывает наблюдателей.

## Формат сдачи дня

Каждый день сдаётся как: код в ветке + видео-скринкаст в комментарии в общей таблице. Видео — БЕЗ звука: мы снимаем консоль, где просто печатается текст. Никакого закадрового текста, никакой озвучки. Ценятся кратко и по делу: команда → вывод → следующий шаг.
