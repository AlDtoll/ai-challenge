# Vue

## История

Vue.js создал Эван Ю в 2013 году после ухода из Google. Целью было соединить лучшее из Angular и React в лёгкой библиотеке. Первый релиз вышел в феврале 2014. Vue 2 (2016) закрепил прогрессивный подход, Vue 3 (2020) переписан на TypeScript и представил Composition API. Vue популярен в китайском сообществе и в Европе.

## Прогрессивный фреймворк

Vue называют прогрессивным: его можно подключить одним script-тегом для оживления одной страницы, а можно строить большие SPA с роутером, стором и SSR. Компонент состоит из трёх блоков: template с HTML-подобной разметкой, script с логикой, style с CSS. Такая структура ближе к традиционной вёрстке, чем JSX.

## Реактивность

Vue 3 использует Proxy для реактивности: доступ к свойству через ref или reactive автоматически отслеживается. Изменение значения перерисовывает только зависимые компоненты. Composition API даёт функциональный стиль организации логики, аналогично хукам React, но с сохранением отдельных блоков template/script/style.

## Экосистема

Официальные пакеты Vue: Vue Router — маршрутизация, Pinia — стор (заменил Vuex), Vite — сборщик, разработанный Эваном Ю. Nuxt — фреймворк уровня Next.js, но для Vue: SSR, роутинг по файловой системе, серверные API. Vue отлично подходит и для встраивания в старые сайты, и для полноценных SPA.

## Vue vs React

Vue часто сравнивают с React. Для новичков Vue проще: HTML-шаблоны привычнее, чем JSX, реактивность встроена без необходимости useState. Для крупных команд React может быть предпочтительнее из-за большей экосистемы и вакансий. По производительности разница минимальна в реальных приложениях. TypeScript в Vue 3 поддержан на первом классе, но React исторически интегрирован лучше. По количеству звёзд на GitHub Vue опережает React, но по количеству вакансий на LinkedIn — сильно отстаёт. Выбор между ними для нового проекта — часто вопрос предпочтений команды и локального рынка.
