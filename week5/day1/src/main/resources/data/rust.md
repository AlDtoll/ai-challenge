# Rust

## Появление

Rust начал разрабатывать Грейдон Хор в 2006 году как личный проект. С 2009 года разработку поддержала Mozilla. Первая стабильная версия 1.0 вышла в мае 2015 года. В 2021 году создан Rust Foundation с участием AWS, Google, Microsoft и Huawei. Название Rust отсылает к грибку-паразиту, устойчивому и повсеместному — качества, которые ценил основатель.

## Модель владения

Ключевая инновация Rust — система владения на уровне типов. Каждое значение имеет единственного владельца; при передаче происходит перемещение или клонирование. Ссылки могут быть либо множественными неизменяемыми, либо единственной изменяемой. Заимствование проверяет borrow checker во время компиляции. Эти правила гарантируют отсутствие гонок данных и висячих указателей без сборщика мусора.

## Экосистема

Пакетный менеджер cargo и реестр crates.io стали стандартом. Rust активно применяется в системном программировании, backend (Actix, Axum, Rocket), эмбеддед-разработке, WebAssembly. Firefox постепенно переписывает компоненты движка на Rust, ядро Linux начиная с версии 6.1 принимает драйверы на Rust. Проекты Servo, Deno, Vector написаны на Rust целиком.

## Обучение

Rust известен крутой кривой обучения: программисты сталкиваются с borrow checker'ом каждые несколько строк первого месяца. Официальная книга The Rust Programming Language распространяется бесплатно и считается одной из лучших языковых документаций. Compiler делает подсказки исключительно понятными, часто предлагая точный правильный код.

## Rust vs C++

Rust часто позиционируется как современная альтернатива C++. Общее: обе языки без сборщика мусора, целятся в системное программирование, дают доступ к аппаратуре. Отличия: Rust проверяет память во время компиляции, C++ полагается на дисциплину программиста. В C++ есть исключения, множественное наследование, множество способов сделать одно и то же — Rust проще и однозначнее. C++ имеет 40 лет истории, огромную экосистему, легаси-код. Rust моложе, но быстро набирает вес. Крупные проекты постепенно переносят критичный код: Firefox, Chrome (частично), драйверы Linux. По зарплатам Rust-разработчики — одни из самых высокооплачиваемых в индустрии.
