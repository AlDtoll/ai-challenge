# Kotlin

## История и авторы

Kotlin разработан компанией JetBrains, первое публичное упоминание — 2011 год. Стабильная версия 1.0 вышла в феврале 2016. Название происходит от острова Котлин рядом с Санкт-Петербургом — местом основной разработки. В 2017 году Google объявил Kotlin официальным языком для Android, а в 2019 сделал его приоритетным над Java.

## Ключевые особенности

Kotlin строго типизирован, но благодаря выводу типов код лаконичен. Null-безопасность на уровне типов: типы делятся на nullable (String?) и non-nullable (String), что устраняет большинство NullPointerException на этапе компиляции. Data classes автоматически генерируют equals, hashCode, toString. Extension functions позволяют добавлять методы к существующим классам без наследования.

## Корутины

Корутины — легковесные конкурентные вычисления, работающие поверх потоков ОС. Ключевые слова suspend и приостановка функций без блокирования потоков позволяют писать асинхронный код в стиле обычного последовательного. Flow — реактивные потоки с обратным давлением. Одна JVM может держать миллионы корутин, в отличие от нескольких тысяч потоков.

## Платформы

Kotlin компилируется в JVM-байткод, JavaScript, а через Kotlin Native — в машинный код для Windows, Linux, macOS, iOS. Kotlin Multiplatform позволяет иметь общий бизнес-код и платформо-специфичный UI. Jetpack Compose — декларативный UI-фреймворк для Android; Compose Multiplatform распространяет ту же модель на десктоп и iOS.

## Kotlin для Android

Google рекомендует Kotlin как язык номер один для Android с 2019 года. Более 95% топовых приложений в Google Play используют Kotlin. Android Studio поддерживает Kotlin из коробки, миграция с Java может делаться модуль за модулем — обе версии сосуществуют. Jetpack Compose переписал UI-стек Android: декларативные UI-компоненты вместо XML-разметки и наследования View. Библиотеки Android KTX добавляют идиоматичные Kotlin-обёртки над Android API. Coroutines заменили RxJava в большинстве новых проектов из-за более простого API и лучшей интеграции с корутинами.
