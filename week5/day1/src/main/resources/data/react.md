# React

## История

React — JavaScript-библиотека для построения пользовательских интерфейсов. Разработана в Facebook, впервые применена в новостной ленте в 2011 году, опубликована как opensource в мае 2013 года на JSConf US. Автор — Джордан Валк. React изменил парадигму фронтенда, сделав компонентный подход мейнстримом.

## Ключевые идеи

React строится вокруг компонентов — переиспользуемых кусков UI. JSX — расширение JavaScript, позволяющее писать разметку прямо в коде. Virtual DOM минимизирует прямые манипуляции с реальным DOM: React строит виртуальное дерево, сравнивает его с предыдущим и применяет только различия. Однонаправленный поток данных упрощает отладку.

## Хуки

Хуки, представленные в версии 16.8 (2019), позволяют использовать состояние и другие возможности React в функциональных компонентах. Основные: useState — локальное состояние, useEffect — побочные эффекты, useMemo и useCallback — мемоизация, useContext — доступ к контексту. Пользовательские хуки инкапсулируют переиспользуемую логику.

## Экосистема

Вокруг React выросла обширная экосистема: Next.js — фреймворк с SSR и роутингом, Redux и Zustand — управление состоянием, React Query и SWR — работа с сервером, styled-components и Tailwind — стилизация. React Native переносит компонентную модель на нативные iOS и Android приложения. React Server Components — новая парадигма серверного рендеринга.

## React в 2026

React прошёл путь от компонентной библиотеки до платформы. React Server Components позволяют выполнять компоненты на сервере и отправлять клиенту готовый результат — меньше JavaScript в бандле, лучше SEO. Suspense управляет асинхронной загрузкой данных декларативно. Concurrent Mode делает рендер прерываемым для лучшего отклика. Однако сложность экосистемы выросла: выбор между Next.js, Remix, Gatsby, самописным Webpack требует знаний. Критики говорят, что порог входа стал выше, а React утратил свой изначальный лозунг просто UI-библиотека. Тем не менее по опросам StackOverflow React остаётся самым используемым фронтенд-фреймворком в мире.
