# Go

## Появление

Go, часто называемый Golang, создан в Google в 2007 году Робертом Гриземером, Робом Пайком и Кеном Томпсоном. Стабильная версия 1.0 выпущена в марте 2012. Мотивация авторов — упростить разработку крупных серверных систем: компиляция должна быть быстрой, зависимости явными, синтаксис простым. Логотип — стилизованный суслик.

## Философия дизайна

Go намеренно минималистичен. В языке нет наследования классов, обобщений в первой версии, исключений и макросов. Форматирование кода стандартизировано утилитой gofmt: у любой команды один и тот же стиль. Интерфейсы неявные, что упрощает архитектуру. Обобщения добавили только в Go 1.18 (2022), после многолетних дискуссий.

## Конкурентность

Модель конкурентности построена на горутинах — легковесных потоках, управляемых рантаймом, — и каналах, через которые они общаются. Философия don't communicate by sharing memory; share memory by communicating. Одна программа легко держит сотни тысяч горутин. Планировщик мультиплексирует их на потоки ОС.

## Применение

Go доминирует в облачной инфраструктуре: Docker, Kubernetes, Terraform, Prometheus, InfluxDB, etcd написаны на Go. Причины — статически линкуемые бинарники без зависимостей, быстрые компиляция и запуск, простая многопоточность. Веб-серверы, микросервисы, CLI-инструменты — типичные ниши.

## Экосистема Go

Стандартная библиотека Go — одна из сильнейших сторон языка. Она включает готовые HTTP-сервер и клиент, шифрование, JSON, работу с базами данных, HTML-шаблоны. Многие мелкие сервисы можно писать вообще без сторонних зависимостей. Go-модули с 2018 года решили проблему управления зависимостями. Компиляция даёт статически линкуемые бинарники размером в несколько мегабайт, работающие без runtime. Тестирование встроено: файл с суффиксом _test.go рядом с кодом, команда go test. Профилировщик pprof интегрирован в стандартную библиотеку и даёт flame-графы CPU и памяти.
