# Python

## История языка

Python создал Гвидо ван Россум в 1989 году, работая в исследовательском центре CWI в Амстердаме. Первая публичная версия 0.9.0 вышла в феврале 1991 года. Название языка — отсылка не к змее, а к британской комик-труппе Monty Python. Ключевые версии: Python 2.0 (2000) с генераторами и сборщиком мусора, Python 3.0 (2008) с несовместимыми улучшениями и Unicode по умолчанию.

## Философия

Философия языка сформулирована в The Zen of Python (PEP 20): красивое лучше уродливого, простое лучше сложного, читаемость важна. Python предпочитает единственный очевидный способ сделать что-то. Отсутствие обязательных фигурных скобок и обязательные отступы принуждают писать структурированный код. Динамическая типизация ускоряет прототипирование.

## Экосистема

Python широко используется в анализе данных (NumPy, pandas, Jupyter), машинном обучении (PyTorch, TensorFlow, scikit-learn), веб-разработке (Django, Flask, FastAPI), автоматизации, научных вычислениях. Пакетный менеджер pip и PyPI хранят более 500000 библиотек. Виртуальные окружения (venv, virtualenv, poetry) изолируют зависимости проектов.

## Производительность

Стандартная реализация CPython интерпретирует байткод, из-за чего Python в 10-100 раз медленнее C. Проблема глобальной блокировки интерпретатора GIL долго мешала параллелизму. Проект nogil в Python 3.13 представил экспериментальный режим без GIL. Для ускорения используют PyPy (JIT-компиляция), Cython, Numba, или пишут критичный код на C/Rust.

## Обучение и вакансии

Python занимает первое место в TIOBE Index с 2021 года и лидирует в опросах Stack Overflow среди новичков. Официальный туториал docs.python.org — качественная точка входа. Из книг ценятся Fluent Python Лучано Рамалью, Effective Python Бретта Слаткина. Онлайн-курсы: Coursera, Udemy, DataCamp. Реальные проекты в резюме важнее сертификатов. Средняя зарплата Python-разработчика в России в 2026 году: junior — от 90 000 рублей, middle — 200-350 000, senior и data scientist — от 400 000. Востребованные ниши: ML/AI, data engineering, DevOps, backend. За рубежом медианная зарплата в США — около 150 000 долларов в год.
