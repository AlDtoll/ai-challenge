# Видео-формат челленджа

## Немой скринкаст

Все видео дней челленджа снимаются как **немой скринкаст консоли**: экран, где просто печатается текст. **Звука нет** — никакого закадрового рассказа, никакой озвучки, никаких кавычек в стиле «а сейчас мы посмотрим». Только чистый экран.

Формат сценария внутри видео строго один: **что печатаю → что получаю → следующий шаг**. Ни одного «за кадром».

## Длительность

Обычно около 2 минут на день. При этом видео должно охватить главное:

1. Команда старта (`.\gradlew.bat :weekN:dayN:run --console=plain -q`).
2. Первый интересный вывод (сколько чанков, какая длина контекста, статус LLM-ответа).
3. Демонстрация фичи дня (например, `--rag` vs без `--rag`).
4. Финальный вывод или сравнение.

## Что записывать в PROGRESS

Для каждого дня в `~/ai-challenge/docs/weekN/` пишем:
- `weekN_dayM_video_script.md` — точный сценарий: строка ввода → ожидаемый вывод.
- При необходимости — `weekN_transcript.md` (для недель с длинной лекцией).

Для дней недели 5 (RAG) видео-скрипт содержит команды `--build`, `--ask "..." [--rag]`, `--compare`.

## Запуск дня — стандартная преамбула

Перед записью видео Данил обычно:

1. `chcp 65001` — включает UTF-8 в PowerShell.
2. `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8` — исправляет декодирование дочернего процесса.
3. Чистит state в `~/.ai-challenge/*.json` — чтобы начать «с нуля», без старого контекста.
4. Запускает основную команду `.\gradlew.bat :weekN:dayN:run --console=plain -q`.
