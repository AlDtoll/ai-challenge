# План недель челленджа

Челлендж рассчитан на 7 недель по 5 дней (25 рабочих дней). Каждая неделя — своя тема.

- **Неделя 1 (дни 1–5):** первый LLM API, промпт-инжиниринг, стратегии рассуждения, температура, сравнение моделей через OpenRouter + судья.
- **Неделя 2 (дни 6–10):** Agent-класс + Telegram-интерфейс, персистентный контекст (JSON per chat_id), подсчёт токенов и стоимости.
- **Неделя 3 (дни 11–15):** архитектура агента — слои памяти (short-term / working / long-term), персонализация (профиль пользователя), Task State Machine, инварианты, controlled transitions.
- **Неделя 4 (дни 16–20):** Model Context Protocol (MCP) — клиент (day16), свой сервер по Streamable HTTP (day17), планировщик + фоновые задачи (day18), пайплайн из инструментов (day19), оркестрация нескольких MCP-серверов через function-calling (day20).
- **Неделя 5 (дни 21–25):** Retrieval-Augmented Generation (RAG). День 21 — стратегии чанкинга (fixed vs structural) с оценкой Recall@3 и MRR. День 22 — первый RAG-запрос: агент в двух режимах (с RAG / без RAG) + 10 контрольных вопросов.
- **Неделя 6:** ещё не объявлена.
- **Неделя 7:** финальный проект.

## Отличия от MCP (для сравнения)

RAG — про **внутренние знания**, подключаемые во время инференса. MCP — про **внешние источники и действия** (API, инструменты). Обе техники не взаимоисключающие, часто используются вместе.
